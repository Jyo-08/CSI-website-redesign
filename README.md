# CSI VIT Chennai Website

A futuristic and interactive website developed for the CSI VIT Chennai student chapter. The project focuses on creating a modern cyberpunk-inspired user interface with smooth animations, responsive layouts, and engaging navigation.

## Features

- Fully responsive landing page
- Cyberpunk themed UI design
- Smooth scrolling navigation
- Interactive navbar navigation
- Animated hero section
- Glowing cursor effect
- Floating particle background
- Animated statistics counters
- Event showcase section
- Domains section
- Core team section
- Social media integration
- GSAP powered animations
- Hover tilt card effects

## Technologies Used

- HTML5
- CSS3
- JavaScript
- GSAP (GreenSock Animation Platform)
- ScrollTrigger Plugin

## Sections Included

### Hero Section
- Main landing page
- Animated title and subtitle
- Explore Events button
- Smooth scroll navigation

### About Section
- Introduction to CSI VIT Chennai
- Mission, Vision and Community cards
- Cyber grid animated background

### Stats Section
- Animated counters for:
  - Members
  - Events
  - Workshops
  - Hackathons

### Event Arena
- Showcase of technical events
- Interactive event cards
- Hover effects and animations

### Domains Section
- Web Development
- App Development
- Artificial Intelligence
- UI/UX Design

### Team Section
- Core team member cards
- Interactive hover effects

### Social and Contact Section
- Instagram integration
- LinkedIn integration
- Official website link
- Contact details

## Animations and Effects

The website uses GSAP and CSS animations to create:
- Scroll-triggered animations
- Smooth section transitions
- Floating particle effects
- Glowing neon elements
- Interactive hover effects
- 3D tilt card interactions

## Navigation

The navbar includes smooth scrolling to:
- About
- Events
- Domains
- Socials

The Explore Events button scrolls directly to the contact/social section.
